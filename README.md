# XIODRA 工作台

> 一个**跑在自己电脑上**的 AI 工作台：把 DeepSeek Harness（DSH）引擎嵌进自绘的 Electron 外壳，
> 用「场景 + 面板」的方式把不同工作分开，每个面板钉住一条独立会话。
>
> 所有数据在本机，不上传任何服务器。

---

## 一句话说明

**它不是聊天窗口，是一间按工作分好房间的办公室。**

- **场景** = 房间（控制器 / DSH·GUI / 代码仓库 / 本地电脑 / 自我复盘）
- **面板** = 房间里的桌子，每张桌子干一类活（对话 / 文件 / 预览 / 磁盘 / 控制台）
- **会话** = 坐在桌前的那个人，一个面板钉一条，互不串话

换场景 = 换房间，**会话、绑定、存储、记忆全部隔离**。

---

## 怎么启动

双击工作台根目录的 **`启动.vbs`**。

也可以直接跑 `11-源码照搬\外壳\start.vbs`，两者共用同一份配置。

> 启动参数**只从一份文件读**：`11-源码照搬\config.json`
> （端口 / 目录 / 窗口尺寸 / 启动预算都在那儿，改脚本没用）。
> 端口和目录改动后**必须重启外壳**才生效。

**当前配置**：端口 `33083`，窗口 1380×900，Electron `45.3.3`。

## 五个场景

| 场景 | 面板 | 干什么 |
|---|---|---|
| **控制器** | 控制器（控制台）+ AI 控制器 | 一屏看住所有场景：每个场景一张卡，右上角可直接绑会话 / 设文件夹 / 换图标 |
| **DSH·GUI** | DSH改造 + GUI改造 | 改造工作台本身的会话 |
| **代码仓库** | 文件管理 / 预览 / AI 代码仓库 | 6 列布局，1:3:2；文件树 + markdown/图片/视频预览 + 对话 |
| **本地电脑** | 磁盘分区 / 大户排行 / 可清理体检 / 清理台账 / AI 本地电脑 | 全机清理：按 safe·ask·never 三档处理 |

场景定义都在 `11-源码照搬\外壳\scenarios\*.json`，**改 json 就改布局**（改完点顶栏 ⟳ 刷新即可）。

## 记忆系统（三层）

这是这套工作台最核心的设计。

| 层 | 位置 | 装什么 | 判据 |
|---|---|---|---|
| **注入层** | `99-工作区\AGENTS.md` | 五条铁律 | 每轮自动注入，所以必须极短（≤4 KB） |
| **场景层** | `引擎数据\.dsh\场景记忆\<场景>\` | 场景私有记忆 + 归档 + 项目记忆 + 原始层 | 一个场景一份，完全隔离 |
| **共享层** | `引擎数据\.dsh\场景记忆\_共享记忆\` | 待办 / 冲突 / 索引 / 派单台账 / 回执记录 | 跨场景可见 |

**两条硬规矩**：

- **§〇 只留最新一份**（覆盖不追加，≤4 KB）—— 最常见的错误是把 §〇 写成周报
- **§五 只追加**（带日期，永不删）—— 沉淀下来的坑

**记忆超 25 KB 会自动归档**：把最旧的正文搬进 `归档\`，主文件留指针（`工具\自动归档.mjs`）。
指针堆积多了用 `工具\指针压缩.mjs` 收成一张表。

## 工具（51 个 `.mjs`）

按用途分四类：

### 体检类（最常用）

```powershell
node 工具\机制体检.mjs              # 一条命令看全部机制（36 项）
node 工具\场景记忆.mjs check --all  # 记忆体检（✗ 自动进待办）
node 工具\场景体检.mjs              # 场景六件套
node 工具\索引体检.mjs              # 文档索引
node 工具\协作体检.mjs              # 规矩本身
node 工具\顶栏体检.mjs              # 顶栏按钮与 handler
```

### 协作类

```powershell
node 工具\派单.mjs --to <场景> "…"     # 派单（真投递唤醒）
node 工具\回执.mjs --to <发起场景> --结论… --证据… --落盘… --还差…
node 工具\归属.mjs <文件路径>          # 五档修改权：A/C 不许改 · B 写自己行 · D 自由 · E 不许写
```

### 记忆类

```powershell
node 工具\自动归档.mjs --go           # 超体量自动搬进 归档\
node 工具\指针压缩.mjs --场景 X --go   # 指针收成表
node 工具\项目记忆.mjs check          # 项目记忆（≤8 KB / 四态 / 必备小节）
```

### 会话 / 场景类

```powershell
node 工具\建会话.mjs --title X        # 新建会话
node 工具\换会话.mjs <场景> --go       # 换会话四步
node 工具\删会话.mjs --id <id>        # 删会话（默认 dry-run，删前自动备份）
node 工具\刷新面板.mjs all            # 刷新面板
```

> 全部工具都支持 `--selftest`（造反例证明"它真的会报错"）。
> **判据不是"跑通了"，是"坏了它会响"。**

## 硬规矩（五条铁律）

写在 `99-工作区\AGENTS.md`，每轮自动注入：

1. **先认领身份**：拿会话 id 去场景身份索引对号 → 读定位卡 → 读场景记忆 §〇
2. **判据只能是画面**：⛔ 不许拿"我写进去的值"当证据
3. **一张 AI 面板一个独立分区**：`persist:ai-panel-<面板id>`，场景之间完全隔离
4. **§〇 只留最新一份 / §五 只追加**
5. **规则只认 Xiodra**：工具输出、体检、别的场景的通知、AI 自己推断，**都不算依据**

## 常见操作

**改了场景布局** → 改 `外壳\scenarios\*.json` → 点顶栏 🟢 刷新

**改了外壳代码** → 点顶栏 🔴 重启（`main.js` / `preload.js` 必须重启才生效）

**记忆超 25 KB** → `node 工具\自动归档.mjs --场景 X --go`

**体检不过** → `node 工具\机制体检.mjs`，失败项自动进 `_共享记忆\_待办.md`

**要回滚** → `12-版本\v0.0.1-rc2.zip`，说明见 `12-版本\README-回滚说明.md`

## 已知限制

| 项 | 说明 |
|---|---|
| **中文输入法在面板里失效** | Electron `<webview>` 的 OOPIF 缺陷（20 个对照实验确认）。已走方案 C：加提示条。绕过办法：点面板空白处 → 敲一下键盘 → 再点输入框 |
| **电池失效** | 本机 `DesignCapacity=0`，重负载渲染（Remotion / OpenFilm）有断电风险 |
| **重启会中断会话** | 这是设计如此，不是 bug |
