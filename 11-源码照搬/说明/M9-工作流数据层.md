## 三、流程 JSON 格式（唯一出处）

```json
{
  "name": "视频工作流",
  "desc": "一段素材从原始文件到成片交付的固定工序",
  "nodes": [
    { "id":"n1", "type":"input", "name":"取素材",
      "input":[], "output":["原始素材.mp4"], "next":["n2"],
      "state":"pending", "note":"可选备注" }
  ]
}
```

- `type`：`input` / `process` / `ai` / `tool` / `output` / `text`
- `state`：`pending` / `running` / `done` / `error`（⛔ 只许四词）

---

## 四、状态机（唯一判据 = `canTransition()`）

```
pending ──▶ running ──▶ done
                   └──▶ error
```

三条硬规则：

1. **只许单向**：`done` / `error` 是终态，不许自己改回去（要重跑必须 `--reset`）
2. **前置没 done 就不许 running**：跑之前会检查所有指向它的节点是否都 done
3. **有环直接拒绝**：DFS 三色检测，有环则报 `a → b → a`（跑不完）

**实测**（`--selftest` 11/11）：

```
⛔ 「n2」的前置还没 done：n1        ← 依赖拦截生效
✓ n1：pending → running → done
✓ n2：pending → running            ← 前置 done 后放行
```
