# 使用说明

> 这份文档讲**这台机器上这一份**工作台怎么用。命令与路径都对着 `D:\Xiodra Worktable\11-源码照搬` 的真实布局写，
> 不是对外发布模板的通用说法。

## 一、它是什么

装在你自己电脑上的 AI 工作台外壳：

- **外壳**（Electron + 纯 JS）负责窗口、顶栏、场景标签栏、面板网格、主题壁纸；
- **引擎**（DSH）负责 AI 本体，跑在 `127.0.0.1:33083`，由外壳自动拉起；
- **场景**（`外壳\scenarios\*.json`）决定每个标签页里有哪些面板、每张 AI 面板绑哪条会话；
- **场景记忆**（`引擎数据\.dsh\场景记忆\`）是每场景的私有笔记 + 共享地盘表。

引擎与记忆都在你本机，不上传。

## 二、第一次用

```powershell
cd 外壳
npm install
cd ..
双击 启动.vbs
```

`启动.vbs` 与 `外壳\start.vbs` 都从根目录 `config.json` 读参数（端口、窗口尺寸、引擎目录、数据目录），
**改完端口或数据目录必须重启外壳才生效**。

当前配置：

| 项 | 值 |
|---|---|
| 端口 | `33083`（`config.json` 的 `port`） |
| 窗口 | 1380×900，最小 1000×660 |
| 引擎目录 | `引擎\`（DSH 源码，指向外部安装） |
| 数据目录 | `引擎数据\.dsh\` |

## 三、日常

| 想干什么 | 怎么做 |
|---|---|
| 切场景 | 点顶栏的场景标签（未选中的收成图标，鼠标滑上去才展开标题） |
| 刷新当前场景 | 顶栏 `⟳`；或 `node 工具\刷新面板.mjs all` |
| 换壁纸 / 调外观 | 顶栏 `⟳` 左边的主题按钮 → 壁纸 / 外观两页 |
| 改面板布局或换类型 | 面板标题栏右侧 `⇄`（回到面板类型选择器）；坐标改 `外壳\scenarios\<场景>.json` 后 `⟳` |
| 改面板标题 | **双击标题**，输入完按 `Enter` 保存到场景 json |
| 放大一块面板 | 标题栏 `▲` 展开到整屏，`Esc` 收起 |
| 看某条会话到底有没有绑上 | 面板标题行小字（`已钉住 · X`）+ `外壳\captures\<面板id>.png` |
| 打包带走 | `node 工具\封装.mjs --out <盘根>:\发布` |
| 出包前自检 | `node 工具\发布前检查.mjs`（默认跳过 `引擎\` 与 `引擎数据\`；加 `--all` 才扫） |

## 四、场景与会话怎么管

```powershell
node 工具\建会话.mjs --list                    # 本项目已有会话（标题 · id）
node 工具\建会话.mjs --title "控制器"           # 建会话（空会话不进侧边栏，脚本会塞一句话再打断）
node 工具\换会话.mjs 控制器 --go                # 换会话四步：建同名 / 旧会话改名+真归档 / 新会话开场写「先读 §〇」/ 回写配置+索引+自检
node 工具\归档会话.mjs <session-id> --go        # 从外部真归档（会话自己归档自己只会成功一半）
```

绑定的三个字段写在场景 json 里（`sessionId` / `sessionTitle` / `pinTarget`），
改完会**自动同步**到 `外壳\scenarios\_场景身份索引.md`（`main.js` 的 `syncIdentityIndex()`）。
⚠ 手工直接改 json 不会触发同步，那种情况要自己回来把表改对。

判据只有两条：**面板标题行小字** 与 **`外壳\captures\<面板id>.png` 截图**。
⛔ 不要拿"我写进 json 的 sessionId"当成功证据。

## 五、记忆怎么用

```powershell
node 工具\场景记忆.mjs list              # 每个场景缺什么
node 工具\场景记忆.mjs check --all       # 体检（结构 / 指纹 / §〇 / 项目 / 归档 / 会话绑定）
node 工具\场景记忆.mjs stamp --场景 控制器 # 场景 json 改了要重盖章
```

- `§〇 当前交接`：只留最新一份，**覆盖写**，≤4KB；
- `§五 长期记忆`：**只追加**，一条一行带日期，永不删；
- 共享的东西（地盘表 / 协作规矩 / 派单台账）在 `引擎数据\.dsh\场景记忆\_共享记忆\`。

## 六、跨场景协作

```powershell
node 工具\派单.mjs --to 控制器 "现象/怎么做/怎么验/回一句"   # 真投递（会唤醒对方会话）
node 工具\派单.mjs --list --me dsh-gui                     # 我发出的没回 / 别人在等我回的
node 工具\派单.mjs --ack <hash>                            # 销账
```

**公告 ≠ 派单**：只落盘不唤醒的通知，实测执行率 8/36。
规矩全文见 `引擎数据\.dsh\场景记忆\_共享记忆\协作规矩.md`。

## 七、常见问题

| 现象 | 处理 |
|---|---|
| 双击 `启动.vbs` 没反应 | 看 `外壳\server.log`；多半是 `ELECTRON_RUN_AS_NODE` 没清掉（启动脚本会自动清，手起 electron 要自己清） |
| 窗口出来但界面停在启动页 | 等引擎就绪（冷启动 30–80 秒，日志 `engine ready in …`）；失败态会留在启动页显示原因 |
| 面板一片空白 | 顶栏 `⟳`；再不行看 `外壳\server.log` 和 `外壳\captures\<面板id>.png` |
| AI 面板显示「未绑定会话」 | 该面板没绑会话，或绑的会话标题在侧栏里找不到（改过名？回来改 `sessionTitle`） |
| 两个面板串到同一条会话 | 它们同名或共用分区 —— 改名 + 各自独立 `persist:ai-panel-<面板id>` |
| 端口被占 | 改 `config.json` 的 `port`，重启外壳 |
| 想换引擎位置 | 改 `config.json` 的 `engineDir`，重启外壳 |
| 改完 `main.js` 没效果 | 改主进程必须**重启整个 Electron**；只改 `renderer\*` 才用 `⟳` / `location.reload()` |

## 八、边界

- 不带引擎本体（`引擎\` 是 junction，指向你自己的 DSH 引擎）；
- `引擎数据\` 整个目录是你的真实数据（会话 / 记忆 / 凭据），**永不发布**；
- 记忆方法论与内部实践文档另有版权；代码 MIT。
