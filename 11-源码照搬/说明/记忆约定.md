# 记忆约定（1 页）

> 这套工作台的记忆是**文件**，不是聊天记录。每个场景一个文件夹，AI 开场先读它。

## 一、放在哪

```
引擎数据\.dsh\场景记忆\
  命令\场景私有记忆.md       ← 这个场景的记忆（唯一真源）
  命令\_文件索引.md          ← 这个场景有哪些文件
  命令\归档\               ← 交接时把旧版挪进来（只进不改）
  _共享记忆\               ← 多个场景都要用的东西
```

## 二、一份私有记忆的格式

- `## §〇 当前交接`：四小节（上次交接 / 当前项目 / 私有记忆变更 / 下一步·卡点），**≤4 KB**
- `## 核心职责`：≥3 条（负责什么 / 不碰什么 / 一句话）
- `## §一 ~ §五`：职责边界 / 现状接口 / 坑与决策（**只追加**）

## 三、四条铁律

1. **§〇 ≤4 KB**：只写"下一轮接手要知道的"，细节进 §五 或归档
2. **交接才归档**：`node 工具\场景记忆.mjs 交接 --场景 <名字>` 会把旧版挪进 `归档\`
3. **只追加**：§五 决策与坑只往下写，不改历史
4. **check 不过别换会话**：`node 工具\场景记忆.mjs check --场景 <名字>`

## 四、常用命令

```powershell
node 工具\场景记忆.mjs list                 # 看每个场景缺什么
node 工具\场景记忆.mjs init --场景 命令      # 生成身份卡/画像（首次）
node 工具\场景记忆.mjs stamp --场景 命令     # 重新生成身份卡/画像
node 工具\场景记忆.mjs 交接 --场景 命令      # 归档旧版 + 补 §〇
node 工具\场景记忆.mjs check --场景 命令     # 自检
```

## 五、跨场景

`node 工具\发消息.mjs --to B站 "帮我看下这个"` —— 纯文件，不发网络请求。对方下一轮读自己的 §〇-通知 就能看到。

## 六、其它工具（机制面）

```powershell
node 工具\建会话.mjs --title "场景名"      # 建会话（必须带 workspaceId；空会话不进侧边栏）
node 工具\换会话.mjs <场景> --go           # 换会话四步：建同名 / 旧会话改名+真归档 / 新会话开场写「先读 §〇」/ 回写配置+索引+自检
node 工具\归档会话.mjs <id> --go           # 从外部真归档（会话自己归档自己只会成功一半）
node 工具\派单.mjs --to <场景> "四件套"     # 真投递派单（公告≠派单，只落盘时执行率 8/36）
node 工具\派单.mjs --list --me <场景>      # 我发出的没回 / 别人在等我回的
node 工具\回执.mjs --to <场景> --结论 …    # 回执四件套校验 + 真投递 + 自动销账
node 工具\归属.mjs <路径>                  # 修改权五档判据（A/C 不许改 · B 写自己行 · D 自由 · E 不许写）
node 工具\刷新面板.mjs all                # 面板自刷新（写 data\reload-panels.cmd，不用手点 ⟳）
node 工具\gpu.mjs ocr                     # 这活要不要上 GPU（唯一判据；拿不到就退 CPU 并记 why）

# 体检（一条命令看全貌）
node 工具\机制体检.mjs                     # 12 项机制全跑，失败自动进待办
node 工具\机制体检.mjs --selftest          # 反例门禁：造违规，确认每项真的会报
```

## 六·二、MCP 工具（外部能力）

| 工具 | 干什么 | 怎么验 |
|---|---|---|
| `mcp__iconfont__search_icons` | 搜 iconfont.cn 的免费图标与插画，返回可直接落盘的 SVG | 直接调一次，看 `hits[].svg` 有没有内容 |

- 服务端 vendor 在 `MCP\mcp-iconfont\`，接入 bundle 在 `MCP\bundle-iconfont\`；
- 上游接口 2026-11-18 变更（要求 `Cookie: ctoken=null`），补丁判据：`node 工具\mcp-iconfont补丁.mjs --check`；
- 包升级后**必须重跑**那个补丁脚本。
