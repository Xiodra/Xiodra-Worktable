# 共享记忆 · 索引

> 这里放「多个场景都会用到」的东西。只有会影响别人的内容才放共享层，其余放各场景自己的记忆。
> 这张表同时是**地盘表**（照搬《05-协作与规矩/三-跨场景协作》§一）：一个场景一行，写清负责什么、不碰什么、写回点在哪。
> **判据**：只有本场景关心 ⇒ 私有；会影响别人 ⇒ 共享（拿不准 ⇒ 私有 + 这里加一行指针，⛔ 别整段复制）。
> 机械抓手：`node 工具\协作体检.mjs` —— 本表行数 ↔ 场景 json ↔ `索引.json` ↔ `areas\*.md` **双向核对**，缺谁多谁点名。

| 场景 | 地盘（卡 + 记忆） | 谁维护 |
|---|---|---|
| 控制器 | `areas/controller.md` ｜ `场景记忆\控制器\场景私有记忆.md` | controller-chat |
| DSH·GUI | `areas/dsh-gui.md` ｜ `场景记忆\DSH·GUI\场景私有记忆.md` | dsh-gui-chat ｜ dsh-gui-p3 |
| 自我复盘 | `areas/self-review.md` ｜ `场景记忆\自我复盘\场景私有记忆.md` | self-review-chat |
| 本地电脑 | `areas/local.md` ｜ `场景记忆\本地电脑\场景私有记忆.md` | local-chat |
| 代码仓库 | `areas/git-scene.md` ｜ `场景记忆\代码仓库\场景私有记忆.md` | git-scene-chat |

> ⚠ `DSH·GUI` 有**两条**常驻会话（GUI改造 / DSH改造），共用一张定位卡与同一份私有记忆，靠面板 id 分辨。
