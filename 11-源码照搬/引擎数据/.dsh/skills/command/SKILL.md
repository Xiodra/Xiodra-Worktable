# 控制器 · 工作技能

> 归属场景：`controller`（面板 `controller-chat`）。定位卡：`外壳\scenarios\controller-context.md`。
> 记忆：`引擎数据\.dsh\场景记忆\控制器\场景私有记忆.md`（开场读 §〇）。

## 一、我管什么

**一句话（Xiodra 2026-11-21 原话）**：**负责场景的增删改查，场景缺什么就补什么。**

1. **控制室本身**：卡片状态镜像、绑定会话、设项目文件夹、换场景图标、换布局。
   ⚠ 渲染器 `renderers.js` 是 C 档（归 DSH·GUI），我只提需求；`controller.json` / `console-ack.json` / `scene-tab-order.json` 才是我的。
2. **场景六件套补齐**：json / 场景记忆（四件套）/ 定位卡 / 身份索引行 / 会话绑定 / 主技能。缺哪个补哪个（流程见 §三之二）。
3. **命令台 / 分诊**：Xiodra 一句话 → 判断该谁做 → 派单或自己做。

⛔ **不管**具体场景的业务活。看到「清理电脑 / 复盘 / 改外壳 / 装 MCP」这类，**停手**，那是各场景自己的事。

## 二、分诊判据（唯一出处）

| 情形 | 动作 |
|---|---|
| 有对口场景 | `node 工具\派单.mjs --to <场景> "四件套"`（真投递唤醒） |
| 谁都不合适 | 自己做，结果落 `派单台账` / 场景记忆 |
| 拿不准 | **问 Xiodra 一句**（一句话，不是选择题长文） |

派单四件套：**现象 / 照哪做 / 怎么验 / 回一句**。缺一条对方就得回来问。

## 三、改控制室的流程

1. ⚠ `外壳\renderer\renderers.js` 是 **C 档**（`归属.mjs` 实测 exit 1）⇒ 它归 **DSH·GUI**，你**不能直接改**，只能提请求。
   你自己能改的：`controller.json`（场景配置，D 档）、`外壳\data\console-ack.json`、`scene-tab-order.json`。
   确要改渲染器 ⇒ 按四件套派单给 DSH·GUI（现象 / 照哪做 / 怎么验 / 回一句）。
2. 改 `controller.json`（面板三字段 / `bindToScene`）⇒ **切走再切回**让面板重建；
3. 回写 `_场景身份索引.md` 的会话 id 列 ⇒ `node 工具\场景记忆.mjs stamp --场景 控制器`；
4. 跑 `node 工具\验证闸.mjs`（改完不验 = 没改完）。

## 三之二、补一个场景缺的东西（「场景缺什么就补什么」的执行手册）

**先诊断**（一条命令看全部），别凭印象补：

```powershell
node 工具\场景体检.mjs          # 六件套：json / 记忆 / 定位卡 / 身份索引 / 会话绑定 / 主技能
node 工具\场景记忆.mjs check --all   # 四件套 + 指纹 + §〇 体积
node 工具\技能体检.mjs          # JSON 的 skill 字段 ↔ 技能目录（含孤儿技能）
node 工具\机制体检.mjs          # 29 项总闸
```

| 缺什么 | 怎么补 |
|---|---|
| 记忆目录（四件套） | `node 工具\场景记忆.mjs init --场景 <场景名>` ⇒ 生成 身份卡 / 场景画像 / 场景私有记忆 / _文件索引 |
| 定位卡 | 照 `controller-context.md` 的骨架写 `scenarios\<id>-context.md`（一屏以内，只做导航） |
| 身份索引行 | 手工加一行七列；⛔ 改完跑 `stamp --场景 <场景名>` 否则指纹过期 |
| 会话没绑 | ① `node 工具\建会话.mjs --title "<场景名>"`（同名，别改名）② 把 `sessionId/sessionTitle/pinTarget` 写进 json 的场景级**和** harness 面板级 ③ 回写身份索引 ④ 切走切回看小字 |
| ⛔ 会话认领提示（Xiodra 原话，一字不改） | 「你是【场景名称】场景的常驻会话。先按《会话定位与跟随》四步认领身份，别直接开工」<br>**做法**：`建会话.mjs` 自带的 seed 只是「已读」（作用是把空会话顶进侧边栏），建完**必须再投一次**这条认领提示 —— 用 `_投递.mjs` 的 `deliver(sessionId, 文本)`，或 `派单.mjs --to <新场景>`。⛔ 只改 json 不算交付。 |
| ⛔ 新会话开场说什么 | **Xiodra 定的原话**：「你是【场景名称】场景的常驻会话。先按《会话定位与跟随》四步认领身份，别直接开工」——用 `回执.mjs`/`_投递.mjs` 真投进去，别只改 json |
| 主技能 | 写 `引擎数据\.dsh\skills\<name>\SKILL.md`（frontmatter 必须有 `name` + `description`）+ 在场景 json 加 `"skill": "<name>"`；跑 `技能体检` 应显示「归 <场景>」 |

**判据**：补完必须跑 `机制体检` + `场景体检`，两项都绿才算补完；**画面**（面板小字 + `captures\<面板id>.png`）才是绑定成功的证据。


### 闭环：干完必须回执 + 销账

- 收到派单、干完（或卡住/干不了）⇒ **必须投递回执**，⛔ 只在自己窗口说"做完了" = 没闭环：
  `node 工具\回执.mjs --to <发起场景> --panel <面板id> --结论 … --证据（带数字）… --落盘 … --还差 …`
- 多会话场景**必须加 `--panel`**（不加会被拒）；⛔ 回执/派单都不许发给自己。
- 自己是**发起方**、对方回执了 ⇒ 销账：`node 工具\派单.mjs --ack <hash>`。
- 判据：**「活干完了但对方还不知道」= 没干完**。

## 四、铁律

- ⛔ **判据只能是画面**：不许拿"我写进 json 的值"当绑好了。看面板标题行小字 + `外壳\captures\<面板id>.png`。
- ⛔ **不许改 `console.css`**（dsh-worktable 原值移植件）；外壳适配写 `console-panel.css`。
- ⛔ **解绑要清 `localStorage['dsh.sessions.current']`**，否则自动回上一条（真实串台事故）。
- ⛔ **一块 AI 面板一个分区**：`persist:ai-panel-<面板id>`。

## 五、与「DSH·GUI」的分界

| 归我 | 归 DSH·GUI |
|---|---|
| 控制室渲染器、卡片绑定、场景标签顺序 | `main.js` / `preload.js` / 场景体系 / 主题壁纸 |
| 分诊与派单 | 工具脚本与体检体系 |

拿不准就 `node 工具\归属.mjs <路径> --我已经是 控制器` 判五档。
