# 本地电脑

## 一、开场

1. 读 `引擎数据\.dsh\场景记忆\本地电脑\场景私有记忆.md` 的 §〇 接手（进度 / 下一步 / 卡点）。
2. 读 `外壳\scenarios\local-context.md`（定位卡：资产地图 / 触发词 / 铁律）。
3. 判据只认画面：`外壳\captures\<面板id>.png` + 面板标题行小字；⛔ 不拿"我写进 json / localStorage 的值"当证据。

## 二、干活

- 面板：`local-drives`（`sys:disks`）· `local-toplarge`（`fs:scan-dir`）· `local-junk`（`pc:junk-scan`）· `local-ledger`（`pc:ledger`）。
- **能删什么，唯一判据是 `工具\垃圾判据.mjs`** —— ⛔ 不在记忆里另立一套。
- 清理纪律：**先列清单等 Xiodra 点头 → 直接删（无暂存）**。

## 三、要改外壳 = 派单，不是自己动手

`renderers.js` / `console-panel.css` / `main.js` / `工具\*.mjs` 都是 **C 档**（`归属.mjs` 实测）。
即便会话权限是 danger-full-access，**档位不会因此改变**：

```powershell
node 工具\归属.mjs 外壳\renderer\renderers.js --我已经是 本地电脑   # 先判档
node 工具\派单.mjs --to dsh-gui --panel dsh-gui-chat --from 本地电脑 "四件套"
```

多会话场景（`dsh-gui` 有两条）**必须带 `--panel`**，否则工具直接拒绝（这是设计，不是 bug）。

## 四、派单四件套（缺一条对方就要回来问）

1. **现象**：可观察，带数字，不写形容词；
2. **照哪做**：文件路径 + 行号 / 唯一出处文档；
3. **怎么验**：命令 + 期望数字 + 画面判据；
4. **回一句**：写明回执给我（`本地电脑 · local-chat`）。

> 派完**自己也要验**：读对方会话投影的 `turnOutline.turns[].prompt` 确认 hash 到了；改完自己跑 CDP + 截图看画面，⛔ 不拿"他说改好了"当结论。

## 五、常见的"数字在骗人"

- **报数超过盘总容量** ⇒ 一定是 bug，先交叉核对 `sys:disks` 的 total（曾出现合计 422 GB 而 C 盘只有 238 GB）。
- **`maxDepth: 0` 经过 `||` 兜底会变成 2**（`Number(0) || 2`）；看进度小字里的**文件数**识别（10,967 = depth-2，真全量 843,271）。
- **限深扫盘的数是假的**：C:\ 一层得 1.73 GB，Users 真实 88.62 GB。
- 全量扫 C 盘 ≈ 84 万文件 / 142.5 GB / ~6 分钟 ⇒ 必须有二级进度 + 可中断。
- 数字只用**当场跑出来**的那一行；⛔ 不拿历史快照里的 GB 当现状。

## 六、收工

1. 结论写回 §〇（覆盖，≤4KB：进度 / 下一步 / 卡点）；新坑写 §五（只追加，带日期）。
2. 定位卡§七「上次进度」一行。
3. 体检：`node 工具\场景记忆.mjs check --all` + `node 工具\场景体检.mjs` 都要 ✓。
4. 派单台账销账：`node 工具\派单.mjs --ack <hash>`（**对方回执 + 我自己验过**才销）。
