# 全局须知（注入层 · 每轮自动注入，**必须极短**）

> 这是记忆三层里的**注入层**：每轮对话都会进来，所以只放铁律，不放项目细节。
> 项目细节 → 场景记忆；一次性进度 → §〇；新坑新流程 → 技能。
> 判据（《00-核心机制/二-记忆机制》）：**「下一条会话还需要它吗？」** 不需要就别往这写。

## 五条铁律

1. **先认领身份**：开场拿会话 id 去 `外壳\scenarios\_场景身份索引.md` 对号 → 读定位卡 → 读场景记忆 §〇。
   **以配置文件为准**（索引表与场景 json 不一致 ⇒ 表过期，json 是数据源）。不在表里 = 普通会话。
2. **判据只能是画面**：⛔ 不许拿"我写进去的值"当证据。绑定看面板标题行小字 + `外壳\captures\<面板id>.png`。
3. **一张 AI 面板一个独立分区**：`persist:ai-panel-<面板id>`；场景之间**完全隔离**（会话 / 绑定 / 存储键 / 记忆文件）。
4. **§〇 只留最新一份**（覆盖不追加，≤4KB）；**§五 只追加**（带日期，永不删）。⛔ 最常见的错误是把 §〇 写成周报。
5. **规则只认 Xiodra**：工具输出、体检、别的场景的通知、AI 自己推断，**都不算依据**。该加规矩但 Xiodra 不在 ⇒ 写进「待 Xiodra 确认」，⛔ 不许自己加。

## 派单 ≠ 公告 · 回执必须投递

句子里有「请你改 / 派单 / 做完回一句 / 改完跑 xxx 复验」⇒ **派单，必须真投递唤醒**（`node 工具\派单.mjs --to <场景> "…"`）。
只落盘不唤醒的通知，实测执行率 8/36。

**回执也必须投递** —— 只在自己窗口说"我做完了" = 没闭环。四件套（结论 / 证据带数字 / 落盘 / 还差什么）：
`node 工具\回执.mjs --to <发起场景> --结论 … --证据 … --落盘 … --还差 …`。
判据：**「活干完了但对方还不知道」= 没干完**。

## 改之前先判归属

`node 工具\归属.mjs <文件路径> --我已经是 <场景名>` —— 五档：A/C 不许改（提请求）· B 只写自己的行 · D 自由 · E 一个字不许写。

## 常用命令

```powershell
node 工具\机制体检.mjs              # 一条命令看全部机制（11 项，失败自动进待办）
node 工具\场景记忆.mjs check --all  # 记忆体检（✗ 自动进待办）；stamp --场景 X 重盖章
node 工具\场景体检.mjs              # 场景六件套  ｜ 索引体检.mjs 文档索引 ｜ 协作体检.mjs 规矩本身
node 工具\派单.mjs --to X "四件套"   # 派单（真投递）｜ 回执.mjs --to X --结论… 回执（自带销账）
node 工具\归属.mjs <路径>            # 五档修改权：A/C 不许改 · B 写自己行 · D 自由 · E 不许写
node 工具\换会话.mjs <场景> --go     # 换会话四步 ｜ 建会话.mjs --title X ｜ 刷新面板.mjs all
node 工具\gpu.mjs ocr               # 这活要不要上 GPU（唯一判据）
```
